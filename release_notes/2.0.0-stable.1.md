# Vibeshine 2.0.0-stable.1 - 2026-09-21

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Changes
- Brought Vibeshine to Linux, with support for Arch Linux and CachyOS on KDE Plasma Wayland, including HDR streaming, virtual displays, and Steam and Lutris libraries.
- Added Remote Monitor, turning additional Moonlight devices into independent extra displays alongside the primary game stream.
- Added native DualSense support, including complete wireless haptics and adaptive triggers on Linux. For fully wireless DualSense haptic feedback, we recommend pairing Vibeshine on Linux with the [VRR Moonlight Client](https://github.com/Nonary/moonlight-qt) running on a Linux client.

## Fixes
- Fixed many minor bugs across streaming, input, displays, and installation to improve everyday reliability.
