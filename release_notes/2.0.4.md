# Vibeshine 2.0.4 - 2026-11-01

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes

- Fixed a Windows installer security check that rejected valid drive-root permissions on some systems. Added validation before removing an existing installation, so a rejected replacement leaves the working host installed, and improved installer diagnostics. Linux was unaffected.
