The global limiter is selected explicitly with `frame_limiter_provider = global`. Automatic/Proton providers use it for streams without a managed Steam game, while managed Steam games retain their direct-launch limiter path. It reads a short-lived cap at presentation time, supports fractional FPS, and stops limiting after stream cleanup or lease expiry. The first stream owns the policy until the final shared runtime stop; RTSP/WebRTC joins preserve its cap or disabled policy, and helper-crash retries use that original policy. The generation-bound broker authorizes only a bounded rate and starts the writer as the selected desktop user; the privileged host does not read or write user-controlled lease paths.

The layer applies to compatible Vulkan processes of the packaged architecture, including DXVK/vkd3d-proton, after they load the installed layer. It does not add an OpenGL/wined3d limiter, a 32-bit layer to a 64-bit package, or support for isolated Flatpak Steam/host AppImage packaging. Games already running before layer installation need restarting. Native Steam container discovery is designed to work without per-game environment changes but still requires a real Proton smoke test. Known host, compositor, and Steam UI processes are excluded. This work does not prove frame-generation capture cadence correct or eliminate MangoHUD benchmark stutter.
