# Vibeshine 1.19.0-beta.4 - 2026-08-30

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Changes
- Added managed private virtual displays on Linux, including Remote Monitor sessions, HDR output, GPU-resident capture, and pre-login session handoff.
- Added native CUDA/NVENC encoding on Linux and made it the default NVENC backend, with presentation-driven capture pacing and faster duplicate-frame filtering.
- Added configurable Steam and Lutris library integrations with automatic synchronization, artwork discovery, and recent-game policies.
- Added Proton-aware MangoHud frame limiting and NVIDIA Smooth Motion controls for Linux game launches.
- Added DualShock 4 controller emulation on Linux.
- Added installable Arch and CachyOS release packages with Secure Boot-ready DRM module handling and a signed repository publication workflow.

## Fixes
- Improved Linux virtual-display recovery across reconnects, resumes, compositor restarts, driver updates, system shutdown, and multi-client handoffs.
- Fixed virtual-display scaling, GPU identity, HDR color, audio resumption, and frame cadence during Linux streams.
- Fixed Steam and Proton launches losing runtime environments, launch-option semantics, frame limits, Smooth Motion settings, or cached runtime data.
- Fixed Linux Remote Input support and made secondary game resumes launch-safe without leaving stale transports behind.
- Hardened Linux integration and settings workflows, including provider visibility, advanced controls, artwork handling, and everyday defaults.
