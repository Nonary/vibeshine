# Vibeshine 1.19.0-beta.3 - 2026-08-22

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Changes
- Windows installers now consume the pinned producer-built [libvirtualgamepad v0.1.0-beta.2](https://github.com/Nonary/libvirtualgamepad/releases/tag/v0.1.0-beta.2) package; Vibeshine signs its driver catalog and setup tool as part of the MSI signing request.
- Automatic VHF gamepad selection now uses supported console profiles only. The reserved generic HID and PID profiles remain unavailable pending an accepted public USB PID.

## Fixes
- Fixed beta installers so clean systems receive the complete Vibeshine Virtual Gamepad driver and source-device package instead of only cleanup assets.
