# Vibeshine 1.16.0-beta.1 - 2026-05-27

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Changes
- Added the bundled experimental Vibeshine Virtual Display Driver as an opt-in Windows display driver, while keeping SudoVDA as the default. This may or may not have better performance than the existing driver, but under my testing it is noticably smoother and also retains EDID and HDR settings.

## Fixes
- Stabilized bundled virtual display creation, recovery, cleanup, HDR activation, probe handling, and stream teardown.
- Fixed WebRTC browser stream latency capping and synchronized capture teardown during video reinitialization.
- Fixed Moonlight pairing cleanup and Web API CSRF mutations.
- Fixed AV1 HDR advertisement, HDR capability probing, and startup encoder probing on Windows.
